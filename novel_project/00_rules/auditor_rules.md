# Auditor 检测规则

本文件供 Auditor Agent（Layer 1 规则检测 + Layer 2 语义审计）使用。

---

## Layer 1：规则检测（零 LLM，纯代码）

### 1. 黑词扫描

出现即扣分的禁词：

```
不禁、宛如、仿佛、某种程度上、不可否认、
深吸一口气、瞳孔骤缩、值得一提的是、
嘴角勾起一抹弧度、倒吸一口凉气、
心中暗道、目光如炬、浑身一震、
一抹、一丝、一缕、某种程度
```

### 2. 黑句式扫描

- "不是...而是..." 排比句
- "这标志着"、"这意味着" 总结性评价
- "值得注意的是" 过渡
- 每段都 "起-承-转-收" 过度工整

### 3. 段落长度均匀性

段落长度变异系数 CV < 0.15 → AI 味嫌疑

### 4. 转折词重复

同一转折词（然而/但是/不过/忽然/竟然）≥ 3 次/千字 → 标记

### 5. 套话密度

"此外""值得注意的是""需要指出""从某种意义上" > 3 次/千字 → 标记

### 6. 生理反应禁令

- 禁止：心脏猛地一跳、瞳孔骤缩、浑身一震
- 替代：用具体物理交互（捏碎茶杯、后退半步、手指收紧）

---

## Layer 2：语义审计（按需触发 LLM）

### 7. 设定冲突

对比 state.json + public.md，检查角色行为是否与已知设定矛盾。

### 8. 剧透/越界披露

对比 reveal_ledger.yaml，检查是否提前揭示了 forbidden_before 中的信息。

### 9. 对话声纹一致性

对比 voice.md，检查角色对话是否符合其声纹特征。

### 10. 叙述者替读者下结论

检查是否有叙述者直接替读者做出判断的句子。
