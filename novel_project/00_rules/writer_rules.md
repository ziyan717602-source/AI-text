# Writer 前置规则（3-5 条致命禁令）

本文件是 Writer Agent 唯一需要遵循的规则。其余检测规则在 Auditor 层执行。

## 铁律 1：叙述者不得替读者下结论

读者能从行为推断的意图，叙述者不得直接说出。
- ✗ 他想看周腊能不能活
- ✓ 只写踢水囊的动作，让读者自己判断

## 铁律 2：禁止"不是……而是……"句式

出现即判定违规。改用直述句。

## 铁律 3：禁止总结性句尾

- ✗ 这一刻，他明白了……
- ✗ 他终于意识到，这一切的意义在于……
- ✓ 只写动作或沉默，让读者自己总结

## 铁律 4：禁止空洞心理分析

- ✗ 核心风险不在今晚吵赢
- ✓ 他心里转了一圈，知道今晚不是吵赢的问题

## 铁律 5：POV 不越权

只写视角角色能看到、听到、触到、闻到的内容。
禁止写其他角色的内心活动。禁止写视角角色不在场的事件。
