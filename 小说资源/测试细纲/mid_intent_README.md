```
ch001: 试探博弈（紧张）→ 部分合作（谨慎乐观）
ch002: 恐惧迷茫（压抑）→ 内视震撼 → 暴风雨顿悟（爆发）→ 从容（平静）
ch003: 情感摊牌（残酷）→ 理性布局（冷静）→ 被人鄙视（不在意）→ 承诺未来（留白）
```

## 测试价值

- **声纹区分**：刘得宜（冷静克制）vs 周腊/钱当迁（圆滑世故）vs 李笑颜（受伤愤怒）vs 玉之灵（骄傲直率）
- **信息揭示节奏**：ch002 的内视场景是全书最大的"设定揭示"之一，测试 Writer 能否写出震撼感而不变成设定说明书
- **情绪复杂度**：ch003 刘得宜用温柔语气说最锋利的话，测试"表面温柔内里冷酷"的写作难度
- **防剧透**：三章的 must_not_reveal 形成递进梯度
